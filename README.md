## Selected Projects

### 1. [ORCA Control Tower](https://github.com/EslamTagElsir/orca-control-tower)
**Supply-chain decision intelligence · Predictive analytics · Explainable AI**

A deployed decision-support prototype that goes beyond retrospective reporting. It combines calibrated shipment-risk prediction, delay-severity estimates with uncertainty intervals, SHAP explanations, and what-if scenario analysis.

**Highlights:** CatBoost, LightGBM, FastAPI, React, TypeScript, SHAP, conformal prediction.

[Explore the live application](https://orca-control-tower.vercel.app) · [View source code](https://github.com/EslamTagElsir/orca-control-tower)

### 2. [Sanad — سند](https://github.com/EslamTagElsir/Sanad)
**Bilingual RAG · Customer-support agent assist · Human-in-the-loop AI**

An agent-assist copilot for e-wallet support. It retrieves relevant knowledge from support articles, company policies, and resolved tickets, then drafts replies in Arabic, Egyptian Arabic, or English. Confidence handling, clarification questions, and escalation help keep a human employee in control before any reply is sent.

**Highlights:** Multilingual embeddings, retrieval, confidence calibration, OpenRouter, FastAPI, JWT, SQLite.

### 3. [NabatGuard AI](https://github.com/EslamTagElsir/NabatGuard-)
**Agricultural knowledge assistant · Retrieval-Augmented Generation**

A tomato-crop assistant that retrieves relevant agricultural information and uses it to ground responses to user questions.

**Highlights:** LangChain, ChromaDB, Hugging Face embeddings, OpenRouter, Streamlit.

[Try the Streamlit demo](https://oajayabumtnnxobqssva49.streamlit.app/) · [View source code](https://github.com/EslamTagElsir/NabatGuard-)

### 4. [NileMart Retail BI Dashboard](https://github.com/EslamTagElsir/Nilemart-retail-powerbi-dashboard)
**Power BI · Retail analytics · Data modeling**

A five-page dashboard analyzing sales, profit, customers, stores, and products across a three-year period. The model uses a star schema and includes 22 DAX measures for time intelligence, profitability, ranking, and retail KPIs.

**Project dataset:** Synthetic data — 10 stores, 800 orders, 19.53M revenue, and 5.29M profit.

### 5. [GlobalFlow Supply Chain Dashboard](https://github.com/EslamTagElsir/Globalflow-supply-chain-powerbi-dashboard)
**Power BI · Supply-chain analytics · Operational KPIs**

A five-page report covering sales, delivery performance, regional trends, and supplier performance. Includes a star-schema model, Power Query cleaning, and 18 DAX measures.

**Project dataset:** Synthetic data — 585 analyzed orders across four regions.

### 6. [n8n HR Automation — AI-Powered ATS](https://github.com/EslamTagElsir/n8n-HR-Automation)
**Workflow automation · AI-assisted recruitment operations**

An Applicant Tracking System prototype built with four connected workflows, covering CV intake, AI-assisted candidate evaluation, HR review, interview scheduling, and daily status summaries.

**Highlights:** n8n, OpenRouter, Google Sheets, Gmail, Cal.com.
